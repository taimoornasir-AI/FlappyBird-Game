# Flappy Bird Game

Flappy Bird is a fun and addictive 2D game where players control a bird attempting to navigate through a series of pipes without colliding. This project is a recreation of the classic game, designed using HTML, CSS, and JavaScript in a single file for simplicity.


# 🚀 Features
- Smooth and responsive controls.
- Randomly generated pipes for endless gameplay.
- Score tracking system.
- Pixel-perfect collision detection.
- Restart option to replay instantly.



# 📂 Project Structure

Flappy-Bird-Game/

# 🛠️ Installation

1. # Clone the Repository:
   bash
   git clone https://github.com/ahmadXplore/Flappy-Bird-Game.git
   cd Flappy-Bird-Game
   

2. # Open the Game in Your Browser:
   Open `index.html` in any modern web browser to play the game.


# 🎮 How to Play
1. Use the **spacebar** (or tap) to make the bird flap its wings.
2. Navigate the bird through the gaps between pipes.
3. Avoid touching the pipes or the ground to keep playing.
4. Aim to achieve the highest score possible!

# 📝 Customization
   Change Bird Skin:  Replace `assets/bird.jpg` with your desired bird image.
   Modify Pipe Speed: Adjust the speed variable in the JavaScript section of `index.html`.
   Game Difficulty:  Tweak pipe gaps or bird gravity in the JavaScript code.
